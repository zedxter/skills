# Version 3.0 Release Notes

Version 3.0 brings dark mode and faster rendering, along with a change to browser support.

## New: Dark mode

Give your charts a dark appearance to complement your application’s theme.

## Improved: Rendering performance

Charts render faster in version 3.0, helping your interface feel more responsive.

## Breaking change: IE11 support removed

Internet Explorer 11 is no longer supported. Applications that need IE11 compatibility should remain on version 2.x.

## Upgrading

Before upgrading, confirm that your supported browsers exclude IE11. Review your charts in both light and dark themes to check colors, labels, and readability.
